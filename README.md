# UIKit Layout Engine

Declarative cross-platform flexbox and grid constraint solver for desktop and terminal UI frameworks.

## Features
- Sub-millisecond Cassowary & Flexbox layout calculation
- High-DPI scaling and fractional pixel snapping across Linux, macOS (ARM64), and Windows
- Automated cross-platform visual & integration verification suite
